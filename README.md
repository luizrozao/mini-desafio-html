# 💻 Portfólio - Mark Zuckerberg

Página pessoal desenvolvida em HTML e CSS durante o curso de **Desenvolvimento de Sistemas do SENAI**.

## 📋 Sobre o Projeto

Este projeto consiste em uma página de portfólio de um desenvolvedor web, contendo informações pessoais, habilidades, projetos desenvolvidos e um formulário para contato.

A página foi desenvolvida com foco na utilização de **HTML semântico**, organização de conteúdo e estruturação de formulários e tabelas.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
